# SANTIS OS Branch Policy

## Protected Branches

- main
- develop

## Rules for main

- Requires pull request
- Requires passing CI
- Requires review
- No force push
- No deletion

## Rules for develop

- Requires passing CI
- Prefer pull request
- No force push
