# SANTIS OS Deletion Policy

No code is deleted without classification.

## Classification

### Alive
Used by production or actively developed.

### Dormant
Not currently active but may contain reusable logic.

### Dead
Unused, duplicated, broken, or replaced.

### Unknown
Requires manual review.

## Deletion Flow

1. Detect
2. Classify
3. Quarantine
4. Test
5. Delete
6. Document

## Quarantine Location

_archive/phase-0-dead-code

## Rule

If uncertain, classify as Unknown and do not delete.
