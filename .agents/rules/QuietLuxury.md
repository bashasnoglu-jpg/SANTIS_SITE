# Quiet Luxury UI/UX Standard

This rule enforces the "Quiet Luxury" design system for Santis OS.

## Principles
- **No cheap gradients**: Avoid high-contrast, saturated, or complex gradients. Stick to subtle, natural transitions.
- **No noisy UI**: Interfaces must have high negative space, minimal text, and low element density.
- **No uncontrolled animation**: All motion must be deliberate, slow, cinematic, and predictable. Use only controlled Framer Motion or GSAP Observers when explicitly approved.
- **No generic SaaS visuals**: Avoid generic illustrations, standard avatars, or overly playful UI components.
- **Editorial, cinematic, calm, premium UI only**: The interface should feel like an editorial layout or a high-end luxury spa catalog.
