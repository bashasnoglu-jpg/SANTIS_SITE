# Phase 0: Reality Lock Workflow

This workflow ensures the fundamental stability and deterministic nature of the Santis OS foundation.

1. **Verify Canonical Stack**: Confirm that no forbidden dependencies (e.g., npm/yarn, alternative ORMs) are present.
2. **Establish CoreState**: Initialize the single source of truth. Ensure no shadow states exist.
3. **Enforce Zod Boundaries**: Audit all API endpoints and event payloads to confirm strict Zod runtime validation.
4. **Lock UI System**: Validate that only "Quiet Luxury" approved components and cinematic animations are active.
5. **No Technical Debt**: Remove any zombie files, dead code, or duplication before proceeding to the next phase.
